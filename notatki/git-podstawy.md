Noo... trochę tych komend jest
git init - tworzy repozytorium
git config - ustawia/wypisuje konfigurację repozytorium
git status - pokazuje pliki untracked, modified i w poczekalni
git log - wypisuje wszystkie commity
git diff - pokazuje wszystkie zmiany względem poprzedniego commita
git add - dodaje pliki do poczekalni
git commit - commituje zmiany w plikach z poczekalni do repozytorium
git commit -m - git commit, ale od razu dodajesz opis
git branch - wypisuje wszystkie branche
git switch - zmienia brancha
git switch -c - tworzy brancza i zmienia się na niego
git restore - przywraca plik zmieniony do stanu sprzed zmian
git restore --staged - cofa plik z poczekalni do untracked/modified
